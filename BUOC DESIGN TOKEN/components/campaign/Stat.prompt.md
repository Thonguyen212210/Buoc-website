A single headline statistic — big serif display number with a caption.

```jsx
<Stat value="248" label="Nhà hảo tâm" />
<Stat value="12" label="Ngày còn lại" tone="onDark" align="center" />
```

Use in a row for campaign metrics. `tone="onDark"` over the purple header; `align="center"` for centered groups.
