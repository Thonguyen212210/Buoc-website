Small status / category pill.

```jsx
<Badge variant="success" dot>Đang gây quỹ</Badge>
<Badge variant="accent">Giáo dục</Badge>
```

Variants: `neutral` (default), `accent` (gold), `success`, `warning`, `error`, `solid` (purple fill), `onDark` (over purple). `dot` adds a status dot; sizes `sm`/`md`.
