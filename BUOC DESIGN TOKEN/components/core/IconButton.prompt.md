Square icon-only button — for share, like, close, and nav affordances.

```jsx
<IconButton variant="soft" label="Chia sẻ"><Share2 size={18} /></IconButton>
```

Variants: `solid`, `soft` (default, tinted purple), `ghost`, `onDark` (use over the purple night-sky header). Sizes `sm`/`md`/`lg` (32/40/48px). Always provide `label`.
