Pill-shaped call-to-action button for Bước — warm, rounded, gently lifted on hover and shrinks slightly on press.

```jsx
<Button variant="accent" size="lg" iconRight={<ArrowRight />}>
  Quyên góp ngay
</Button>
```

Variants: `primary` (deep purple, default), `accent` (gold gradient — reserve for the single hero action), `secondary` (purple outline), `ghost` (text-only). Sizes: `sm` / `md` / `lg`. Pass `full` to stretch full width (common on mobile and inside cards). Icons go in `iconLeft` / `iconRight` as nodes (e.g. Lucide SVGs).
